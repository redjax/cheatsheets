# Lf <!-- omit in toc -->

## About

[`lf`](https://github.com/gokcehan/lf) is a TUI file manager heavily inspired by `ranger`.

## Usage

| Command / Key | Description |
|--------------|-------------|
| `j` / `k` | Move down / up |
| `h` | Go to parent directory |
| `l` / `Enter` | Open file or enter directory |
| `gg` | Jump to top of list |
| `G` | Jump to bottom of list |
| `Ctrl-d` / `Ctrl-u` | Scroll half-page down / up |
| `Ctrl-f` / `Ctrl-b` | Scroll page down / up |
| `x` | Delete file |
| `d` | Cut (move) file |
| `y` | Copy (yank) file |
| `p` | Paste file |
| `a` | Create file |
| `A` | Create directory |
| `r` | Rename file |
| `R` | Reload directory |
| `v` | Toggle selection |
| `V` | Visual select range |
| `u` | Unselect |
| `U` | Clear all selections |
| `Space` | Toggle mark |
| `/` | Search forward |
| `?` | Search backward |
| `n` | Next search match |
| `N` | Previous search match |
| `zh` | Toggle hidden files |
| `:help` | Open help menu |
| `:set hidden` | Show hidden files |
| `:set hidden!` | Toggle hidden files |
| `:map` | Show keybindings |
| `:cd <path>` | Change directory |
| `:rename` | Rename selected file |
| `:delete` | Delete selected file |
| `!cmd` | Run shell command |
| `$cmd` | Run shell command and wait |
| `%cmd` | Run shell command asynchronously |
| `&cmd` | Run shell command in background |
| `zr` | Refresh directory view |
| `q` | Quit lf |
