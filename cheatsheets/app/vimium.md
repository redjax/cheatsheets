# Vimium Browser Extension <!-- omit in toc -->

## About

[Vimium](https://vimium.github.io) is a browser extension that adds Vim-like navigation keybinds to your browser.

## Usage

### Cheatsheet

| Keybind | Action |
| ------- | ------ |
| `?` | Show help |
| `j`     | Scroll down |
| `k`     | Scroll up   |
| `gg` | Scroll to the top of the page |
| `G`  | Scroll to the bottom of the page |
| `d`  | Scroll a half-page down |
| `u`  | Scroll a half-page up |
| `h`  | Scroll left |
| `l`  | Scroll right |
| `r`  | Reload the page |
| `yy` | Copy the current URL to the clipboard |
| `p` | Open the clipboard's URL in the current tab |
| `P` | Open the clipboard's URL in a new tab |
| `i` | Enter insert mode |
| `v`| Enter visual mode |
| `gi` | Focus the first text input on the page |
| `f` | Open a link in the current tab |
| `F` | Open a link in a new tab |
| `gf` | Select next frame on the page |
| `gF` | Select page's main/top frame |
| `/` | Enter find mode |
| `n` | Cycle forward to next find match |
| `N` | Cycle backward to previous find match |
| `H` | Go back in tab history |
| `L` | Go forward in tab history |
| `t` | Create new tab |
| `J` | Go one tab left |
| `K` | Go one tab right |
| `g0` | Go to first tab |
| `g$` | Go to last tab |
| `yt` | Duplicate current tab |
| `x` | Close current tab |
| `X` | Restore closed tab |
| `o` | Open URL, bookmark, or history entry |
| `O` | Open URL, bookmark, or history entry in a new tab |
| `b` | Open a bookmark |
| `B` | Open a bookmark in a new tab |
| `T` | Search through open tabs |
